- 판정: 처리량·평균 지연 비율이 ±10% 안이고 실패·비정상 종료가 없으면 통과(CPU·메모리는 기록만).

## Put 분석

### 프로파일(Rust Put 20초, 스레드 32, 1MiB)

- 쓰기 19,186건(959 ops/s), task-clock 90.2 s, user 32.4 s / sys 54.8 s, 컨텍스트 스위치 177만, 페이지 폴트 802만.
- 상위 샘플: `native_queued_spin_lock_slowpath` 19.8%(`futex_wake ← __unlock` 9.8%, `futex_wait ← __lock` 8.4%) = musl 할당기(mallocng) 전역 락 경합. 그다음 SHA-256 서명 12.1%, 소켓 복사, `clear_page_erms`(요청마다 새로 잡는 1MiB 버퍼의 페이지 0 채우기).
- 서버가 빠른 이 장비에서는 락 대기가 요청 지연에 그대로 더해진다(가상 장비·KSAN에서는 서버 지연에 묻혀 처리량 차이로 나타나지 않았다).
